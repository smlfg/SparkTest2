# TROUBLESHOOTING
# ============================================================================
#
# Problem: "No module named 'unsloth'"
# Solution: Install from git:
#   pip install "unsloth[colab-new] @ git+https://github.com/unslothai/unsloth.git"
#
# Problem: "CUDA out of memory" during pip install
# Solution: Install packages one by one:
#   pip install torch transformers
#   pip install unsloth[colab-new] @ git+https://github.com/unslothai/unsloth.git
#
# Problem: "Could not find a version that satisfies the requirement"
# Solution: Update pip:
#   pip install --upgrade pip setuptools wheel
#
# ============================================================================
# TEACHING: Dependency Management Best Practices
# ============================================================================
#
# 1. ALWAYS use a virtual environment:
#    python -m venv venv
#    source venv/bin/activate  # Linux/Mac
#    venv\Scripts\activate     # Windows
#
# 2. Pin versions for reproducibility:
#    transformers==4.37.2  # Good (exact version)
#    transformers>=4.37.0  # OK (minimum version)
#    transformers           # BAD (any version, not reproducible)
#
# 3. Separate dev dependencies:
#    Create requirements-dev.txt for testing/linting tools
#
# 4. Document why you need each dependency:
#    See comments above each package
#
# 5. Keep dependencies minimal:
#    Only install what you actually use
#    Fewer dependencies = fewer conflicts
#
